# 🏥 CareAxis Hospital Management System

An AI-powered Hospital Management System built using Spring Boot.

## Features

- Secure Admin Login (Spring Security)
- Patient Management
- Doctor Management
- Staff Management
- Hospital Billing
- AI Symptom Prediction
- Emergency Bed Tracking
- Appointment Booking
- Dashboard Analytics
- Revenue Reports
- Responsive UI

## Technology Stack

- Java 21
- Spring Boot 3
- Spring Security
- Spring Data JPA
- Thymeleaf
- MySQL
- HTML
- CSS
- JavaScript
- Maven

How to start - 
The application starts with an embedded H2 database for immediate evaluation. Set `DB_URL`, `DB_USERNAME`, and `DB_PASSWORD` to connect MySQL (e.g. `jdbc:mysql://localhost:3306/careaxis`). The supplied staff account is seeded securely through BCrypt at startup; do not expose it on the public site.
